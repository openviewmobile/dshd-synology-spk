Community package source · DSM 7.2+

DeepSeek Harness
for Synology DSM

Run the open-source DeepSeek Harness (dsh) AI agent workspace natively on your NAS. No Docker, no Container Manager, no nested containers.

Download x86_64 SPK Download armv8 SPK Release notes

Unsigned community package. DSM will show a third-party source warning. Verify the SHA-256 checksum from the release before installing.

Option 1: direct SPK install

Download the SPK for your architecture, then use Package Center → Manual Install. Start the package and run sudo /usr/local/bin/dshd-token to open the token URL.

Option 2: experimental Package Center source

This page also publishes static package-source files for DSM. This is an experimental path; direct SPK installation is the supported method.

x86_64 source URL

https://openviewmobile.github.io/dshd-synology-spk/spk-repo/x86_64.json

armv8 source URL

https://openviewmobile.github.io/dshd-synology-spk/spk-repo/armv8.json

In DSM: Package Center → Settings → Package Source → Add. Use the URL matching your NAS architecture, then refresh Package Center.

Do not add both URLs on the same NAS. The static source endpoint cannot filter by architecture server-side, so each file represents one architecture.

Requirements and limitations

  • DSM 7.2 or later; x86_64 or armv8.
  • About 1.1 GB of free space for the installed runtime.
  • A model API key supplied by the user; no model is bundled.
  • UI listens on 127.0.0.1:3080 only; use a DSM reverse proxy for remote access.
  • Tested on DSM 7.2 VirtualDSM; full ARM DSM and hardware validation is continuing.
  • The SPK is unsigned. SHA-256 checksums and GitHub build provenance are available in the release.
