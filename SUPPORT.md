# Support

- Installation and usage: [README](README.md) and [docs/](docs/README.md)
- Questions and ideas: open a GitHub Discussion
- Bugs: use the bug report issue form
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), not a public issue

This is a community package, not a Synology-certified product. Include your DSM
version, NAS architecture, SPK version, and the relevant `dshd` log lines when
asking for help.
