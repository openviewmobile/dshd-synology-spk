## Description

Your NAS can do more than store files. DeepSeek Harness (dsh)
directly on Synology DSM 7.2 — no Docker, no Container Manager, no nested
containers.

One SPK, a bundled Node 24 runtime, and the unprivileged `dshd` package user.
DSM still handles install, start/stop, updates, boot auto-start, and the
Package Center experience.

What is included:
• Native x86_64 and armv8 SPKs
• Package Center install wizard
• Loopback-only dsh UI with token auth
• Default workspace fixed for DSM
• Reverse-proxy and WebSocket guidance
• Open source under MIT

Requirements: DSM 7.2+, ~1 GB free space, x86_64 or armv8. The SPK is an unsigned
community package; verify the SHA-256 on the release page or build it yourself.
